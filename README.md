Indian Employee Data Cleaning using NumPy & Pandas

This project focuses on cleaning and preprocessing a real-world employee dataset using NumPy and Pandas in Google Colab. The goal is to transform raw, inconsistent data into a structured and analysis-ready dataset.

🚀 What This Project Covers
Importing dataset using Google Colab
Handling missing values in both numerical and categorical features
Replacing infinite values (inf, -inf) with NaN and treating them appropriately
Converting float-based columns (e.g., Age, Salary) into clean integer formats
Detecting and handling salary outliers using upper and lower bounds
Removing irrelevant or redundant columns
🛠️ Libraries Used
NumPy
Pandas
Google Colab (files.upload() for dataset import)
⚡ Key Highlights
Filled missing categorical values (Department, Position) using mode
Treated numerical missing values using mean/median strategies
Cleaned invalid values like inf and standardized dataset consistency
Applied outlier handling techniques to salary data
Performed final dataset cleanup for optimal usability
📊 Output

A fully cleaned and preprocessed DataFrame, ready for:

Data analysis
Visualization
Machine learning models
